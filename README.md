

# 로또

## 프로젝트 소개
실제 로또 게임의 핵심 기능을 콘솔 애플리케이션으로 구현하는 미션
사용자는 로또를 구매하고 당첨번호를 입력하여 당첨 결과와 수익률을 계산할 수 있다.

##주요 기능

- 로또 자동 발급: 구입 금액에 맞춰 자동으로 로또 티켓을 발급.

- 당첨 번호 입력: 당첨 번호 6개와 보너스 번호 1개를 입력받음.

- 당첨 결과 및 통계: 구매한 로또와 당첨 번호를 비교하여 등수별 당첨 내역과 총 수익률을 계산.

- 예외 처리: 사용자의 잘못된 입력에 대해 에러 메시지를 출력하고, 성공할 때까지 입력을 다시 요청.

##기능 요구사항
간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
```
1등: 6개 번호 일치 / 2,000,000,000원
2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
3등: 5개 번호 일치 / 1,500,000원
4등: 4개 번호 일치 / 50,000원
5등: 3개 번호 일치 / 5,000원
```
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.


##입출력 요구사항

입력
- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
``` 
14000
```
- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
``` 
1,2,3,4,5,6
```
- 보너스 번호를 입력 받는다.
``` 
7
```
출력
- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
``` 
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```
- 당첨 내역을 출력한다.
``` 
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```
- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
``` 
총 수익률은 62.5%입니다.
```
- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
``` 
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

##프로젝트 구조

```
lotto
├── controller
│   └── LottoController.java  # 프로그램의 전체 흐름을 제어
├── domain
│   ├── Lotto.java            # 로또 1장
│   ├── Lottos.java           # 구매한 모든 로또
│   ├── LottoAnswer.java      # 당첨 번호와 보너스 번호
│   ├── LottoCount.java       # 구매 금액 및 개수
│   ├── LottoResult.java      # 당첨 결과 및 통계
│   └── Rank.java             # 등수 (Enum)
├── service
│   └── LottoMachineService.java # 로또를 생성하는 비즈니스 로직
├── view
│   ├── InputView.java        # 사용자 입력 담당
│   └── OutputView.java       # 결과 출력 담당
└── Application.java          # 프로그램 시작점
```

##구현 목록

### 1. 프로그램 실행 및 흐름 제어[Controller]
 - 전체 게임의 흐름을 순서대로 제어(로또 구매 -> 당첨번호 입력 -> 결과 출력)
 - view와 domain 계층을 중재, while-try-catch 구문을 통해 예외 발생 시 사용자 입력을 반복적으로 요청
   
### 2. 로또 구매
 - InputView: 사용자로부터 로또 구입 금액을 문자열로 입력받아 숫자(int)로 변환.
 - (숫자 형식이 아닐 경우 IllegalArgumentException을 발생.)
   
 - LottoCount(domain): 생성 시점에 구입 금액을 검증.
 - (1,000원 단위가 아니거나 0 이하일 경우 IllegalArgumentException을 발생.)

 - LottoMachineService: LottoCount만큼 Randoms.pickUniqueNumbersInRange(1, 45, 6)를 호출하여 로또를 발행.

 - Lotto(domain): 생성 시점에 로또 번호 목록을 검증.
 - (번호가 6개가 아니거나, 중복되거나, 1~45 범위를 벗어날 경우 IllegalArgumentException을 발생.)

 - OutputView: 발행된 로또 개수와 각 로또 번호를 출력.

### 3. 당첨 번호 입력
 - InputView: 사용자로부터 당첨 번호 6개와 보너스 번호 1개를 문자열로 입력받아 숫자 및 숫자 리스트로 변환.
 - (숫자 형식이 아닐 경우 IllegalArgumentException을 발생.)

 - LottoAnswer(domain): 생성 시점에 당첨 번호와 보너스 번호를 검증.
 - 당첨 번호의 개수, 중복, 범위 규칙을 검증, 보너스 번호의 범위 규칙을 검증, 보너스 번호가 당첨 번호에 포함되어 있는지 중복 여부를 검증.

### 4. 당첨 결과 계산 및 출력
 - LottoResult(domain): 구매한 모든 로또(Lottos)와 정답(LottoAnswer)을 비교하여 당첨 통계를 계산.
 - (enum) Rank를 이용행 등수를 결정, 당첨 횟수 집계
 - 수익률 계산

 - OutputView: LottoResult 객체로부터 데이터를 받아 요구사항 형식에 맞춰 당첨 통계와 총수익률을 출력.
